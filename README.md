### 🚀 About Me

I'm a **Software Engineer & Backend Developer** passionate about building clean, reliable, and maintainable backend systems. I love digging into how systems work under the hood and turning real-world challenges into well-crafted, usable products.

#### 🎯 What I'm Actively Learning & Exploring:
- **Microservices & Distributed Patterns:** Exploring how to split services cleanly (database-per-service), handle distributed transactions (Saga pattern, Outbox pattern), and coordinate event-driven workflows.
- **gRPC & High-Performance Communication:** Learning typed, contract-first communication with **gRPC** and Protocol Buffers for fast, efficient internal APIs alongside message queues.
- **Data-Intensive Systems (*DDIA*):** Digging deep into Martin Kleppmann's book to better understand database internals, replication, partitioning, and building systems that remain reliable as they grow.
- **Software Architecture (*Fundamentals of Software Architecture*):** Studying core architectural traits (scalability, fault tolerance, modularity) and learning how to evaluate real-world engineering trade-offs.
- **Engineering Mindset (*Coder to Engineer*):** Working to go beyond just writing code — caring about testability, clean code structure, observability, and long-term maintainability.
